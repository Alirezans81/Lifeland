## init ui themes

- extract colors from https://lifelands.ir/ and update ui-context.md file
- also use the lifelands.ir ui principles and note them on ui-context.md file
- init tailwindCSS based on their document and nextjs version
- use the extracted colors and update globals.css file
- create cn() function in /lib folder for merging tailwind classes

## when to be done

- tailwindCSS must be initialized properly
- colors must be based on lifelands.ir website and imported to ui-context.md and globals.css files
- also ui principles must be included in ui-context.md file
- cn() function must be created in /lib folder and work properly
